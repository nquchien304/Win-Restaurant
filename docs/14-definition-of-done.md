# 14 — Definition of Done & Review Gates

## Feature-level Definition of Done

- [ ] Linked FR/BR/AC IDs are implemented.
- [ ] Acceptance criteria pass.
- [ ] Relevant unit/integration/API/UI tests added or updated.
- [ ] Invalid input, authorization and failure paths are covered where applicable.
- [ ] API contract/schema/migrations reflect the implementation.
- [ ] No accidental secret, real data, local path or debug endpoint.
- [ ] Logging is useful and redacted.
- [ ] Manual test steps documented for non-automatable hardware/network behavior.
- [ ] Docs and operating instructions updated if needed.
- [ ] Diff is scoped; no speculative framework or unrelated refactor.
- [ ] Tests/commands and results reported honestly.
- [ ] Human reviewer accepts the change.
