# Prompt 06 — Prepare one vertical-slice task (PLAN ONLY)

Read `AGENTS.md` and the relevant approved specs, business rules, ADRs, API contracts and tests. Choose only the task ID supplied by the owner. Do not implement yet.

Produce:
1. A concise restatement of the user-visible behavior.
2. Current code paths and patterns discovered by inspection (for existing repos); do not invent files.
3. Acceptance criteria and failure cases.
4. Expected files/modules and why.
5. API/DB/schema impacts and migration plan.
6. Test plan and exact commands available in the repo.
7. Risks, assumptions and any blocking question.
8. A small ordered implementation plan.

Check the task is bounded, contracts are clear, and every important decision is approved. If the task changes a business rule, contract or architecture, stop and propose the needed decision/ADR first. Output a task plan based on `docs/templates/TASK-TEMPLATE.md`. No code changes.
